# 星點校園 · 學生獎勵系統

手機網頁測試程式，內置 1 位老師、3 位學生和 3 個個人 QR Code。老師掃碼後須先登入，才可依照「學科／行為／活動」選擇中文原因，自訂加分或減分。學生可查閱積分、兌換禮物和預約領取。

## 在電腦和手機測試

需要 Node.js 22.12 或以上。在專案根目錄建立本機 `.env`，設定你要使用的老師帳戶。`.env` 已列入 Git 忽略清單。

```ini
TEACHER_USERNAME=your-teacher-account
TEACHER_PASSWORD=your-local-test-password
```

```sh
npm ci
npm start
```

1. 在電腦和手機連上同一個 Wi-Fi，並用**程式列出的同一個網絡網址**開啟系統，例如 `http://192.168.1.10:4173`。
2. 用老師帳戶開啟「學生 QR Code」下載列印，或在電腦以學生身份開啟「我的 QR Code」。用手機系統相機掃描並開啟網址。
3. 老師手機若未登入，輸入老師帳號和密碼後，系統會開啟原本掃描的學生記分頁。選擇原因和分數後確認。
4. 以學生身份開啟「禮物兌換」並選擇領取時間。兌換會即時扣分，老師可在「領取預約」確認學生已領取。

在 HTTPS 或 localhost 可使用網頁內的掃描器。在同一 Wi-Fi 的 HTTP 網址，請用手機系統相機或上載 QR Code 相片。

| 測試學生 | PIN | 初始積分 |
| --- | --- | ---: |
| 陳小明（3A · 12 號） | `1301` | 85 |
| 李心晴（3A · 08 號） | `1302` | 62 |
| 張宇軒（3B · 15 號） | `1303` | 38 |

示範禮物包括鼓勵貼紙組（25 分）、彩色筆套裝（50 分）和星星筆記簿（80 分）。領取地點為學校圖書館，時間為香港時間的平日 12:45–13:00 或 15:30–15:45。學生可在時段開始前取消預約，積分會退回。

共用版由一個 Node.js 程序儲存資料至 `data/state.json`。可用 `DATA_FILE` 指定檔案位置、`PORT` 指定埠。若經由 HTTPS 反向代理提供服務，可使用 `TRUST_PROXY=1` 並以 `PUBLIC_APP_URL` 設定手機可到達的 QR Code 網址。

`npm test` 驗證教師登入、加減分權限、重試、預約兌換、退款與資料保存。
