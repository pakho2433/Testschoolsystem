# 星點校園 · 學生獎勵系統

這是供試用的手機網頁程式，內置 1 位老師、3 位學生和 3 個個人 QR Code。老師掃碼後可選擇「學科／行為／活動」，再選中文原因，自訂加分或減分。學生可查閱積分，換取禮物及預約領取時間。

## 用兩部裝置測試

需要 Node.js 22.12 或以上。下載或 clone 本專案後，執行：

```sh
npm ci
npm start
```

1. 在電腦和手機連上同一個 Wi-Fi，並用**程式列出的同一個網絡網址**開啟系統，例如 `http://192.168.1.10:4173`。在這個網址產生的 QR Code 才能在該網絡內的手機開啟。
2. 在老師手機登入王老師。在電腦登入其中一位學生，開啟「我的 QR Code」，或用老師帳戶在「學生 QR Code」下載列印。用手機的**系統相機**掃描並開啟網址。
3. 點選加分或減分、類別與原因，輸入任意正整數分數，再確認。學生重新整理頁面即可看到新餘額。
4. 以學生身份打開「禮物兌換」，選禮物、日期和時段後確認。兌換會即時扣分，並在「我的預約」顯示領取資料。老師可在「領取預約」確認學生已領取。

頁面內的「開啟掃描器」支援 HTTPS 網址或 localhost 的相機權限。用 Wi-Fi 的 HTTP 網址測試時，可用手機系統相機掃碼、上載 QR Code 相片或直接開啟測試連結。

| 測試身份 | PIN | 初始積分 |
| --- | --- | ---: |
| 王老師 | `2468` | — |
| 陳小明（3A · 12 號） | `1301` | 85 |
| 李心晴（3A · 08 號） | `1302` | 62 |
| 張宇軒（3B · 15 號） | `1303` | 38 |

示範禮物包括鼓勵貼紙組（25 分）、彩色筆套裝（50 分）和星星筆記簿（80 分）。領取地點為學校圖書館，時段為香港時間的平日 12:45–13:00 或 15:30–15:45。學生可在預約開始前取消，系統會退還積分。

共用版由一個 Node.js 程序儲存資料至 `data/state.json`。可用 `DATA_FILE` 指定檔案位置、`PORT` 指定埠、`TEACHER_PIN` 設定老師 PIN。如果經由 HTTPS 反向代理提供服務，可設 `PUBLIC_APP_URL` 為手機可到達的網址，用於產生 QR Code。測試用帳戶和資料都是示範資料。

## 瀏覽器測試版

`npm run dev` 可在瀏覽器試用，`npm run build:demo` 產生可放到 GitHub Pages 的 `dist-demo` 靜態檔案。瀏覽器版會先顯示王老師的工作台，按「切換身份」即可用學生帳戶兌換。每個瀏覽器各有一份資料，用另一部手機掃碼時會使用該手機自己的資料。需要同步時請使用上面的共用版。

已建置的靜態檔案在 `gh-pages` 分支。如要開放試用網址，請在 GitHub 專案的 **Settings → Pages** 選擇 **Deploy from a branch**，選取 `gh-pages` 和 `/(root)` 後儲存。

`npm test` 可驗證權限、加減分、重試、預約兌換、退款與資料保存。
